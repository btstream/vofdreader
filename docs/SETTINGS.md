# 设置界面设计

状态：已接入桌面阅读器，配置持久化到用户配置目录的 `vofdreader/settings.json`。实际运行截图：

- [`docs/screenshots/settings-light.png`](screenshots/settings-light.png)（阅读，亮色）
- [`docs/screenshots/settings-performance-dark.png`](screenshots/settings-performance-dark.png)（性能，暗色）

## 交互

- 入口：工具栏“设置”图标或 `Ctrl/Cmd+,`。
- 形式：阅读器上方的模态窗口，背景压暗，点击遮罩、右上角 × 或按 `Esc` 关闭。
- 左侧分类，右侧为当前分类的滚动内容；分类切换不离开窗口。
- 控件即时生效并自动保存，底部不设“应用”按钮；仅保留“恢复默认设置”和“完成”。
- “恢复默认设置”使用二次点击确认；保留阅读位置，其余偏好恢复默认。
- 现有实现支持鼠标操作与 `Esc` 关闭；`Tab` 焦点遍历尚未接入。

## 布局

- 宽 880、最高 760 逻辑像素（窗口较小时自动收缩）；左侧导航 188，右侧内容 692。
- 顶部 60 标题区，底部 56 操作区，内容区超出时独立滚动。
- 沿用现有配色与 5px/14px 圆角体系：亮色 `#FFFFFF` / `#F7F8FA` / `#2F6FEB`，暗色 `#1C1F26` / `#17191E` / `#3B76F0`。
- 行高约 50–58：左侧为标题与说明，右侧放开关、分段控件或步进器；分组之间用 1px 分隔线。

### 性能

已实现：

- 渲染缓存上限：64 MiB–2 GiB，默认 256 MiB；整页与分块共享预算。
- 渲染质量：自动 / 标准 / 高清 / 自定义。自动档位按窗口缩放、适应比例和缩放倍数计算，不强制固定 DPI。
- 自定义档位下可分别调整“整页最高 DPI”和“高清分块最高 DPI”，默认 384 / 768。降低上限可减少内存与光栅化时间，提高上限仅在放大查看时更清晰。
- 整页缓存上限：默认 32 张。
- 解析页缓存：默认 12 页。
- 预取前后页面：默认 2 页。
- 邻块预取范围：默认 1 圈。
- 渲染线程数：默认“自动”（CPU 核数的一半，限制在 1–4）；手动可设 1 到本机核数（最多 16）。控制同时渲染的高清分块数量，修改后立即作用于之后的调度，正在进行的任务照常完成。配置文件中的值超过本机核数时按核数生效。

PNG 导出 DPI 属于“文件与缓存”页，默认 144，与屏幕渲染质量分开。

说明文案需保留边界：缓存预算不是进程总内存上限，不含字体、页面树和 GPU 纹理；缓存上限用于后续淘汰与调度，解析页缓存在下次打开文档时应用新值。

## 与现有代码的对应

- `crates/ofd-app/src/settings.rs`：`Settings`、分类结构、校验、JSON 读写和阅读位置。
- `crates/ofd-app/src/settings_view.rs`：模态窗口、控件和 `SettingsAction` 到运行时状态的桥接。
- `crates/ofd-app/src/cache_config.rs`：总预算、整页数量、解析页数量、预取页数与邻块圈数由设置生成，不维护第二份运行时配置。
- 渲染质量档位映射：自动 384/768，标准 192/384，高清 288/576；自定义使用用户值。整页目标仍受缓存预算约束，避免单页超过工作集。
- 主题通过 `Theme::change` 与自绘调色板切换；系统主题由窗口外观订阅驱动。
- 点阵、页面阴影、浮动工具栏、页面间距、搜索自动滚动和默认视图均直接读取设置；页面间距变化会重建连续布局缓存。
- 导出格式与 PNG DPI、最近文件数量和缩略图清理已接入现有导出/最近文件/缓存代码。
- 渲染线程数 `performance.render_threads`（0 = 自动）经 `tiles::concurrency()` 换算为 `ReaderApp::tile_slots`，启动时与每次设置动作后更新。
